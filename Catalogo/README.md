# Catalogo (Expo)

App React Native + Expo del proyecto **Aplicación Serverless**. Ver la documentación completa (stack, deploy, decisiones técnicas, schema SQL) en el [README raíz del repo](../README.md).

## Quick start

```bash
npm install
cp .env.example .env       # completar con credenciales de Supabase
npm run start
```

Tablas esperadas en Supabase: ver [`supabase/schema.sql`](./supabase/schema.sql).
